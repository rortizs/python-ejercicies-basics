# Semana 2: programacion orientada a objetos

Material de apoyo para modelar objetos con estado y comportamiento.

- [Martes](martes/): clase, objeto, identidad, `__init__`, `self`, atributos, metodos, varios objetos y `__str__`.
- [Jueves](jueves/): parametros, retorno, validacion, encapsulamiento, abstraccion, atributos de clase, comparacion, colecciones de objetos y refactor progresivo.

Los ejemplos usan dominios cotidianos y muestran por que una clase resulta util; no presentan una clase como reemplazo automatico de toda funcion.
