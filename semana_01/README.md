# Semana 1: consola y modularidad

Material de apoyo para repasar los fundamentos de Python y organizar un programa en funciones.

- [Martes](martes/): salida, comentarios, variables, tipos, entrada, conversion, operadores y cadenas.
- [Jueves](jueves/): condicionales, logica, conjuntos, listas, diccionarios, ciclos, acumuladores y funciones.

Los ejemplos cubren los 15 temas introductorios y cierran con un menu modular de biblioteca. Las conversiones numericas muestran como reconocer y manejar `ValueError` sin ocultar el error al estudiante.
