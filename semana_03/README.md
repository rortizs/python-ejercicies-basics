# Semana 3: UML

Material de apoyo para identificar clases y objetos y representar un dominio con UML. El foco es el modelo, sin introducir todavia herencia ni polimorfismo.

- [Martes](martes/): diferencia entre clase y objeto, atributos, metodos, notacion necesaria e identificacion de clases.
- [Jueves](jueves/): diagrama de dominio, multiplicidad y estructura maestro-detalle.
